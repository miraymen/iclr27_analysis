# ICLR 2027 score percentiles

https://miraymen.github.io/iclr27_analysis/

Look up an ICLR 2027 submission (OpenReview link, id or title) or type in scores, and see where it stands among all
submitted papers, the papers left after desk rejection, and the active papers: papers above, tied and below by the
plain average of its ratings and by the confidence-weighted average `Σ(rating × confidence) / Σ confidence`.

The page is static: `index.html` reads `static/data.json`.

Data: public reviews on OpenReview. Not affiliated with ICLR or OpenReview.
